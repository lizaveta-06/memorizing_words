"Карточки для заучивания слов."

Приложение для запоминания слов с графическим интерфейсом.

## Требования

ОС: Windows
Компилятор: g++
Сборка: Make
Qt5 (устанавливается через MSYS2)

## Установка и сборка

```bash
git clone https://github.com/lizaveta-06/memorizing_words.git
cd memorizing_words
make
make run
